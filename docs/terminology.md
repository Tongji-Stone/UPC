# Translation terminology

The following choices apply to the manuscript, captions, diagrams, legends, and axis labels. Original English titles and proper names in the bibliography are retained.

| Chinese term | English term |
|---|---|
| 高空跳伞、太空跳伞 | space diving |
| 跳伞运动员 | space diver |
| 出舱高度 | release altitude |
| 几何高度 | geometric altitude |
| 位势高度 | geopotential altitude |
| 自由下降、自由降落 | free fall |
| 收尾速度 | terminal speed |
| 恢复温度 | recovery temperature |
| 平旋 | flat spin |
| 俯仰 | pitch |
| 开伞充气 | parachute inflation |
| 伞阻力面积 | parachute drag area |
| 过载指标 | load factor |
| 有效迎风面积 | effective frontal area |
| 开伞高度 | deployment altitude |
| 比力 | specific force |
| 气动阻力 | aerodynamic drag |

“Space dive” is used for one event; “space-diving” is the adjective. A load factor is dimensionless; a specific force or radial acceleration can instead be expressed as a multiple of g₀. Axis labels consistently distinguish these quantities.

Physical variables are italic in figures; numerals, units, and descriptive subscripts are upright. Diagram labels use text-mode Times New Roman (including italic Greek letters) rather than the body math font. Matplotlib uses the actual Times New Roman regular/italic font files, with fallback disabled. Vector SVG files retain glyph outlines for portability.
